# 不吃亏 / Buchikui

> 消费前多看一眼，消费后少走弯路。

**不吃亏**是一个面向普通消费者的公益性质知识型网站，致力于帮助用户：

- **识别消费陷阱**：在付款前看清合同条款、比较真实总价、识别营销套路
- **留存关键证据**：在履约过程中知道该保存什么、如何保存
- **合理有效维权**：在纠纷发生后明确诉求、选对渠道、写好材料

## 核心原则

1. **先看规则，再付钱** — 所有口头承诺，都要落到文字里
2. **低价有条件，就不叫低价** — 把「起步价」换算成「最终总价」
3. **押金不是商家的备用收入** — 交押金前，先问清楚扣什么、何时退、凭什么扣
4. **证据要在争议发生前保存** — 聊天记录、页面截图、付款凭证，一个都别少
5. **对「限时」「最后名额」保持警惕** — 催你立刻付款的人，通常不希望你仔细比较
6. **预付得越多，风险越大** — 能按次付，就别一次性付多年
7. **不要只和客服吵，要留下可用记录** — 少情绪，多事实
8. **谁主张扣钱，谁就应当说清楚** — 要求对方列明合同依据、事实依据、证据材料
9. **选对渠道，比盲目投诉重要** — 先判断问题，再决定找谁
10. **维权不是「出口气」，是拿回属于你的东西** — 目标具体、金额清楚、步骤留痕

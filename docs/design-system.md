## 五、组件规范

### 5.1 按钮

**主要按钮**（Primary Button）

```css
背景：bg-purple-700
文字：text-white
悬停：hover:bg-purple-800
圆角：rounded-lg
内边距：px-6 py-3
字重：font-medium
```

**次要按钮**（Secondary Button）

```css
背景：bg-white
文字：text-purple-700
边框：border border-purple-700
悬停：hover:bg-purple-50
圆角：rounded-lg
内边距：px-6 py-3
字重：font-medium
```

### 5.2 卡片

**基础卡片**（Card）

```css
背景：bg-white
边框：border border-gray-200
圆角：rounded-lg
阴影：shadow-sm
内边距：p-6
```

**悬停效果**：

```css
阴影：hover:shadow-md
过渡：transition-shadow
```

### 5.3 输入框

**基础输入框**（Input）

```css
背景：bg-white
边框：border border-gray-300
圆角：rounded-lg
内边距：px-4 py-2
聚焦：focus:border-purple-500 focus:ring-2 focus:ring-purple-200
```

### 5.4 导航栏

**顶部导航栏**（Navbar）

```css
背景：bg-white/95 backdrop-blur-sm
边框：border-b border-gray-200
高度：h-16
位置：fixed top-0
层级：z-50
```

## 六、交互模式

### 6.1 首页滚动

- 使用 CSS `scroll-snap` 实现整屏滚动
- 支持鼠标滚轮、键盘方向键、触摸滑动
- 滚动时更新 URL hash 和进度指示器

### 6.2 下拉菜单

- 桌面端：hover 展开，鼠标移出收起
- 移动端：点击展开/收起
- 支持键盘导航（Tab + Enter）

### 6.3 链接悬停

- 颜色变化：`hover:text-purple-700`
- 下划线：`hover:underline`
- 过渡动画：`transition-colors`

### 6.4 按钮悬停

- 背景色加深：`hover:bg-purple-800`
- 阴影加深：`hover:shadow-md`
- 过渡动画：`transition-all`

## 九、无障碍设计

### 9.1 颜色对比度

- 正文文字：对比度 ≥ 4.5:1
- 大标题：对比度 ≥ 3:1
- 交互元素：对比度 ≥ 3:1

### 9.2 键盘导航

- 所有交互元素可通过 Tab 键访问
- 支持 Enter 键激活
- 支持 Esc 键关闭弹窗

### 9.3 屏幕阅读器

- 使用语义化 HTML 标签
- 图片添加 alt 属性
- 表单添加 label 标签

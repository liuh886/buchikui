# 不吃亏 — 设计规范

> 版本：v2.2 | 更新日期：2026-08-20

视觉定位仍然是 **editorial field guide / 消费事故现场手册**：可信、克制、证据优先。设计目标不是把每一段内容都做成一个“模块”，而是让用户沿一条阅读主线快速完成判断和行动。

## 1. 核心原则

- **少层级**：同一信息只出现一次，不重复做导航、标签和解释。
- **案卷感，不是 App 控件感**：编号、分隔线、留白和字号负责层级。
- **少圆角、少胶囊、少阴影**：不靠组件堆叠制造设计感。
- **主线展开，辅助收起**：服务基线、模板等辅助内容默认折叠。
- **证据优先**：黄色只用于证据和关键事实；红色用于风险、编号和品牌识别。
- **移动端不降级**：390px 宽度下无横向溢出，关键动作仍可直接完成。

## 2. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| Ink | `#171715` | 主文字、主按钮、强分隔线 |
| Paper | `#f6f3ec` | 页面背景 |
| Surface | `#fffdf8` | 弹层、模板等抬升表面 |
| Red | `#d94b3f` | Case 编号、风险、品牌识别 |
| Yellow | `#f2cf55` | 证据、选中态、关键事实高亮 |
| Muted | `#777168` | 次要文字 |
| Line | `#d7d0c4` | 常规分隔线 |
| Dark | `#1a1a18` | 立即行动、证据区 |
| Blue | `#3157d5` | 行政/规则提示与焦点状态 |

不使用紫色主色、多彩渐变或装饰性发光。

## 3. Header

Header 只包含：

**品牌 / Case Switcher / 分享**

不再放页内导航。

### Case Switcher

关闭状态：

**当前 CASE 名称 + Chevron**

不要同时显示 CASE 编号、英文标签、“切换”文案等重复提示。

展开状态：

- 目录式 popover / 移动端底部抽屉；
- 列表项可显示 CASE 编号、名称和英文短标签；
- 当前项用浅黄色底 + 左侧红色状态条；
- “随机一个”是轻量文本操作。

## 4. Hero

Hero 由两部分组成：

1. 左侧主张 + 一段定性说明；
2. 右侧深色 Immediate Actions。

不再显示 Hero CASE stamp。

Immediate Actions 默认只展示动作标题，使用 `01 / 02 / 03 / 04` 索引。避免“标题 + 一段解释”重复后续正文。

桌面 Hero H1 约 `50–80px`，移动端约 `42–60px`。

## 5. Progressive Disclosure

辅助信息统一使用原生 `details/summary`，不新增自定义抽屉或第二套组件。

默认折叠：

- 正常服务基线；
- 沟通模板。

折叠 summary 只表达三件事：

**这是什么 / 有多少或能做什么 / 可以展开**

不用额外卡片包裹。

## 6. Scenario List

场景列表就是“找到我的问题”，不再增加 Scenario Locator 轨道。

结构：

**编号 / 场景标题 / 关键事实 + 现在做什么**

默认不显示 `risk` 副标题。

桌面开放式三列；移动端为“编号 + 标题”，正文单列。场景之间使用规则线和留白，不使用 card grid。

## 7. Evidence

Evidence 保持深色整段区域和顶部红线。

- 桌面两列，移动端单列；
- Checkbox 为小方框，完成态使用黄色；
- 分组标题可以保留，但不显示分组解释文案；
- 单项保留材料名、必要的一句说明、确有价值时的时间提示；
- 进度和打印入口放在区块底部，不增加第二个工具栏。

## 8. Route

Route 使用简洁步骤表。

- 不显示 kicker；
- 不显示长篇 intro；
- 保留步骤编号、动作标题、必要说明和官方入口；
- 重要例外或条件可放一个 route note；
- 桌面最多四列，窄屏自动变两列/单列。

## 9. Template

模板默认折叠。

展开后：

- 左侧必要说明；
- 右侧白色文档表面；
- 顶部深色规则线；
- 一个复制按钮。

不让模板在默认状态永久占据整屏。

## 10. Button 与动效

- Radius：`6px`；
- Primary：深色底 + 浅色文字；
- Secondary：透明底 + 中性色边框；
- 不使用 999px pill；
- 动效只用于 hover、CASE 切换和 disclosure；
- 遵守 `prefers-reduced-motion`；
- 所有 button/link/summary 保留 `focus-visible`。

## 11. 响应式

主要断点：

- `960px`：Route 从四列降为两列；
- `860px`：进入移动布局、Case Switcher 底部抽屉、正文单列；
- `480px`：进一步压缩 Case Switcher 和 Evidence 元数据。

移动端底部只保留两个动作：

**找到我的问题 / 查看处理步骤 + 分享 CASE**

## 12. 禁止项

不要重新引入：

- 常驻页内导航；
- Scenario Locator 第二套目录；
- Hero CASE stamp；
- 场景 `risk` 可见副标题；
- 大量 pill / badge / bento 卡片；
- 重复 CTA；
- 为装饰而存在的 icon rows；
- dashboard 式 chrome；
- 已折叠辅助信息的另一套重复摘要。

设计系统继续围绕：

> **内容可信 + 证据优先 + 单一路径 + 克制层级**

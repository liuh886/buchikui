# 不吃亏 — 产品构想

> 版本：v2.0 | 更新日期：2026-08-14

---

## 一、产品定位

### 1.1 一句话定位

**「不吃亏」是一份消费风险识别与合理维权的行动指南。**

它不是又一个投诉曝光平台，而是帮助消费者在**付款前、履约中、纠纷后**三个阶段做出正确决策的工具型内容网站。

### 1.2 使命与愿景

**使命**：让普通消费者在面对商家时，不再因为信息不对称而吃亏。

**愿景**：成为中国消费者最信赖的「消费决策参考」和「维权行动指南」。

### 1.3 核心价值

| 价值 | 说明 |
|-----|------|
| **实用性** | 每一条建议都应该是用户可以立即执行的 |
| **证据导向** | 强调「留什么证据」比「谁对谁错」更重要 |
| **去情绪化** | 不煽动对立，用结构化方式解决问题 |
| **可验证** | 引用的法规、案例、渠道信息必须可查证 |
| **公益性** | 免费、开放、非营利，服务公共利益 |

## 二、目标用户

### 2.1 用户画像

| 用户类型 | 占比估计 | 典型特征 | 核心需求 |
|---------|---------|---------|---------|
| **普通消费者** | 50% | 日常消费中遇到过坑，想避免再次踩坑 | 快速了解常见套路，获得检查清单 |
| **纠纷当事人** | 30% | 正在经历消费纠纷，需要维权指导 | 知道该留什么证据、找谁、怎么写材料 |
| **谨慎决策者** | 15% | 准备大额消费（装修、医美、培训），想提前了解风险 | 深度了解行业套路，获得决策参考 |
| **内容创作者** | 5% | 想分享维权经验，帮助更多人 | 有平台可以沉淀和传播经验 |

### 2.2 用户场景

**场景 1：付款前**

> 小王准备租一辆车自驾游，在下单前想了解一下租车有什么坑。

用户路径：
1. 搜索「租车注意事项」或直接访问不吃亏
2. 浏览首页十条原则，重点关注「押金不是商家的备用收入」
3. 点击进入「如何租车维权」专题
4. 查看「付款前检查清单」，逐项确认
5. 下载或截图保存清单，取车时对照执行

**场景 2：纠纷中**

> 小李还车后，租车公司以「划痕」为由扣了 1500 元押金，但小李认为划痕不是自己造成的。

用户路径：
1. 搜索「租车押金被扣怎么办」
2. 进入「如何租车维权」专题
3. 查看「纠纷后行动指南」
4. 按「第一步：整理证据」清单检查自己有什么证据
5. 使用「沟通话术模板」与租车公司书面沟通
6. 根据「选对渠道」表格决定下一步行动

**场景 3：预防性学习**

> 小张准备办一张健身卡，听说健身房跑路很多，想提前了解一下怎么避坑。

用户路径：
1. 访问不吃亏首页
2. 浏览十条原则，重点关注「预付得越多，风险越大」
3. 点击进入「如何健身房维权」专题
4. 查看「常见坑」和「付款前检查清单」
5. 决定选择月卡而非年卡，或选择有资金监管的平台

## 三、产品价值主张

### 3.1 三阶段价值

| 阶段 | 用户痛点 | 不吃亏提供 |
|-----|---------|-----------|
| **付款前** | 这个商家靠谱吗？合同有什么坑？价格真的划算吗？ | 风险检查清单、条款风险库、价格拆解工具、常见套路预警 |
| **履约中** | 该留什么证据？被加价怎么办？服务缩水怎么记录？ | 场景化证据指南、沟通话术模板、证据留存清单 |
| **纠纷后** | 找谁投诉？怎么写材料？能赢吗？要多久？ | 维权路径导航、文书模板、匿名化案例参考、渠道对比 |

### 3.2 与现有平台的差异化

| 平台 | 模式 | 局限 | 不吃亏的差异 |
|-----|------|------|------------|
| **全国12315平台** | 官方投诉受理 | 只处理投诉，不教用户如何准备 | 不吃亏做**前端决策支持**，让用户在投诉前就有清晰证据和诉求 |
| **黑猫投诉** | 第三方投诉曝光 | 依赖曝光施压，效果不稳定 | 不吃亏不依赖曝光，而是**结构化证据 + 路径规划** |
| **法律咨询网站** | 付费咨询 | 门槛高，费用高 | 不吃亏是**公益知识库**，面向「还没到需要律师」阶段的消费者 |
| **消费评测媒体** | 商品测评 | 关注商品性能，不关注交易风险 | 不吃亏聚焦**交易过程与合同风险** |
| **知乎/小红书** | 经验分享 | 信息碎片化，质量参差不齐 | 不吃亏提供**结构化、可验证、持续更新**的内容 |

### 3.3 核心差异化总结

**不吃亏 = 消费决策的「 checklist 」+ 维权行动的「导航仪」**

- 不是「帮你投诉」，而是「教你怎么准备」
- 不是「曝光商家」，而是「帮你留证据」
- 不是「法律意见」，而是「行动指南」
- 不是「一次性内容」，而是「持续更新的知识库」

### 4.2 首页：十条原则 · HTML PPT

**设计理念**：

首页是用户的第一印象，也是产品的核心价值传递。采用「HTML PPT」形式，每屏聚焦一条原则，通过视觉冲击和简洁文案让用户快速理解并记住。

**交互方式**：

- 整屏滚动（类似 PPT 翻页），每屏展示一条原则
- 支持鼠标滚轮、键盘方向键、触摸滑动
- URL 锚点定位（如 `#principle-3`），方便分享某一条
- 右侧显示进度指示器（01/10 → 10/10）
- 最后一屏提供「开始探索」按钮，引导到案例栏目

# 如何租车维权

## 常见坑

### 坑 1：还车后以「划痕」为由扣押金

**套路描述**：
还车时商家未提出异议，事后以「发现划痕」为由拒绝退还押金，或要求高额赔偿。

**典型案例**：
某消费者租用豪车，按时归还后商家称发现划痕，拒退 1.5 万元押金。法院审理发现商家无证据证明划痕发生在租赁期间，判决全额退还。

**应对策略**：
- 取车时拍照/录像，记录车况（外观、内饰、仪表盘）
- 还车时要求当场验车并双方签字确认
- 如商家事后提出异议，要求其提供证据证明划痕发生在租赁期间

### 坑 2：隐性费用

**套路描述**：
租车时未明确告知保险费、服务费、GPS 费等隐性费用，还车时强制收取。

**应对策略**：
- 付款前要求商家列明所有费用明细
- 确认合同中的费用条款
- 保留付款凭证和费用清单

### 坑 3：事故维修费虚高

**套路描述**：
发生事故后，商家索要远高于市场价的维修费。

**典型案例**：
某消费者租车发生事故，实际维修费约 2000 元，商家索要 11000 元。

**应对策略**：
- 发生事故后立即报警、报保险
- 要求商家提供维修明细和正规发票
- 可自行询价对比，必要时申请第三方评估

## 付款前检查清单

- [ ] 确认租车合同条款，特别是押金、保险、免责条款
- [ ] 确认合同主体与收款主体一致
- [ ] 了解押金退还时限和扣款条件
- [ ] 确认保险覆盖范围和免赔额
- [ ] 了解违章处理流程和费用
- [ ] 确认车辆状况（外观、内饰、功能）
- [ ] 拍照/录像记录车况
- [ ] 保留付款凭证和合同文本

## 履约中注意事项

- 保留所有沟通记录（微信、短信、电话录音）
- 发生事故立即报警、报保险、拍照
- 不要私下与商家协商「私了」后放弃追责
- 定期检查车辆状况，发现问题及时记录
- 保留加油、停车、过路费等票据

## 纠纷后行动指南

### 第一步：整理证据

**必须有的证据**：
- 租车合同文本
- 付款凭证（押金、租金、其他费用）
- 取车时的车况照片/视频
- 还车时的验车记录（如有）

**最好有的证据**：
- 与商家的沟通记录
- 扣款通知和扣款依据
- 维修明细和发票（如涉及维修费争议）
- 第三方评估报告（如有）

### 第二步：书面沟通

**沟通原则**：
- 少情绪，多事实
- 用「时间—订单—问题—证据—诉求—期限」结构表达
- 保留沟通记录

**话术模板**：

> 本人于 {{date}} 在贵平台租车（订单号：{{orderId}}），支付押金 {{amount}} 元。本人已按约定于 {{returnDate}} 还车，还车时贵方未提出异议。
>
> 现贵方于 {{deductDate}} 扣款 {{deductAmount}} 元，但未提供扣款合同依据、验车记录、维修发票及费用明细。
>
> 请于收到本通知后 3 个工作日内提供以下材料：
> 1. 扣款的合同条款依据
> 2. 验车记录（含照片/视频）
> 3. 维修明细和正规发票
> 4. 费用计算方式
>
> 如未妥善处理，本人将向 12315 投诉并保留进一步维权的权利。

## 五、内容策略

### 5.1 内容原则

| 原则 | 说明 | 示例 |
|-----|------|------|
| **实用性优先** | 每一条建议都应该是用户可以立即执行的 | 「取车时拍照录像」而不是「注意保留证据」 |
| **证据导向** | 强调「留什么证据」比「谁对谁错」更重要 | 「要求商家提供维修发票」而不是「商家乱收费」 |
| **去情绪化** | 不煽动对立，用结构化方式解决问题 | 「用时间—订单—问题—证据—诉求结构表达」而不是「骂客服」 |
| **可验证** | 引用的法规、案例、渠道信息必须可查证 | 引用具体法规条款和法院判决 |
| **匿名化** | 案例必须脱敏，不涉及具体商家名称 | 「某租车平台」而不是「XX租车」 |

### 5.2 内容生产流程

```
选题（高频消费场景）
  ↓
调研（法规、判例、投诉数据）
  ↓
撰写（按模板结构化）
  ↓
审核（事实核查 + 法律合规）
  ↓
发布
  ↓
迭代（根据用户反馈更新）
```

### 5.3 内容来源

| 来源 | 类型 | 用途 |
|-----|------|------|
| 法律法规 | 《消费者权益保护法》《民法典》等 | 法律依据 |
| 法院判决 | 中国裁判文书网公开判例 | 参考案例 |
| 投诉数据 | 12315、黑猫投诉等平台公开数据 | 高频问题识别 |
| 用户反馈 | GitHub Issues、用户反馈表单 | 内容迭代 |
| 专家审核 | 法律专业人士 | 合规审核 |

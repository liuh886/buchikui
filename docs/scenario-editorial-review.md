## 这六题是什么

它们是规则边界的合成情境试题，**不是六宗已核实个案的转述**。只有地点变更题明确参考最高法公开个案，并在题目边界说明从培训改成美容的改编。是否自然、有趣仍需内容试玩评审；通过工程测试不能证明这件事。

| 题号 | 关键区别 | 来源与边界 |
| --- | --- | --- |
| rental-operator | 品牌与合同公司不同，不自动等于冒牌 | rental/operator；依据消保条例第13条说明实际经营者信息，不能推成授权书必真 |
| rental-deposit-before | 没到账和超过约定不是同一事实 | rental/deposit；消保条例第20条；时限是题设，不声称现实行业统一七工作日 |
| repair-search-ad | 广告与授权是两个事实 | appliance-repair-trap/search-ad；互联网广告管理办法第9条，官网独立核验是题设 |
| repair-price-before | 明码标价与是否便宜不同 | appliance-repair-trap/repair-pricing；家电维修明码标价规定第3、8条，本轮补齐规则中的市场调节价事实并复核原文 |
| beauty-price-change | 初次办卡与体验同款后续充不同 | beauty-hair/prepaid-refund；预付式消费司法解释第14条例外；不支持七日规则不等于所有退款途径消失 |
| beauty-relocation | 有替代地点与能否按原约接受服务不同 | beauty-hair/relocation-transfer；司法解释第13条，及最高法公开培训地点变更案；是否明显不便仍依具体事实 |

## 撤下原因与后续准入

原“先看价目表再拆”“先付款拿钥匙”“先签折半余额”等题，靠明显不利选项或不自然台词泄露答案；原投诉举报题脱离多数人的现场决定；旧题把留证和谨慎建议当作唯一正解。本轮全部题面重写，重复和证据不足的槽位撤下。

后续新增题先附真实纠纷来源，分开写真实事实、游戏改编和依据；不靠全知坏人、连环倒霉或催促凑戏剧性。不用“仅凭一个词就一定”的套路批量造题；这组六题只用于校准事实边界，不能据此认定已形成成熟的场景游戏题库。

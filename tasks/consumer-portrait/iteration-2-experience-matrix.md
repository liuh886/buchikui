# 第二轮经历特征与题目覆盖矩阵 (Experience Matrix)

日期：2026-10-24 · 状态：A阶段校准完成（G1候选）  
依据：[第二轮工作计划](iteration-2-plan.md)、[产品完成度评估](../../docs/consumer-portrait-pm-assessment.md)、[现行内容规范](../../docs/case-content-standard.md)。

## 1. 核心定位与原则

1. **坚持经历自述，不做人格/能力测验**：问卷仅记录客观遭遇与决策波折，YES 表示“有过”，NO 表示“没有过”。禁止通过 YES/NO 评价消费者的成熟度、性格偏好、警惕性或是否“聪明/粗心”。
2. **从“业务题组”转向“经历机制”**：此前的旅游（2题）、预付（3题）、售后（3题）划分是商品与行业属性，而非消费者的经历模式。本矩阵将现存八题提炼为三类核心经历机制：
   - **机制 A：承诺与实际不符（承诺落差）** —— 商家在签约、宣传或成交时作出的承诺，在实际交付时缩水、打折或偷换概念。
   - **机制 B：服务安排被单方变更（安排变动）** —— 履约的时间、地点、流程或扣款规则被经营者单方面调整，打破消费者原有预期。
   - **机制 C：预付结算受阻与停业波折（结算阻碍）** —— 发生闭店、停业或未履行项目退订时，在清退未用权益或退费结算上发生争议。
3. **等权与不重复计分**：每题只作为一个独立的自述单元；在计算机制权重时，不采用多重计分制造偏差。

## 3. 机制分布与标签覆盖检验

按三大经历机制归类现存 8 题：
1. **机制 A：承诺落差**（3 题）
   - Q1 `survey-tour-museum`（无购物团 -> 加博物馆）
   - Q7 `survey-battery-replacement`（整机换新 -> 只换零件）
   - Q8 `survey-secondhand-business`（个人闲置 -> 售假欺诈）
2. **机制 B：安排变动**（2 题）
   - Q2 `survey-arrival-payment`（到店付款 -> 提前预扣全款）
   - Q5 `survey-training-relocation`（离家近 -> 强迁远地）
3. **机制 C：结算阻碍**（3 题）
   - Q3 `survey-prepaid-gift`（健身闭店 -> 赠送次数退费纠纷）
   - Q4 `survey-annual-closure`（儿童乐园年卡 -> 中途闭店未履行退款）
   - Q6 `survey-photo-unfinished`（写真套餐未做项目 -> 拒绝解除退费）

**分布特征核对**：
- 机制 A（3题）、机制 B（2题）、机制 C（3题），分布均衡，各机制均有 2～3 个不同领域的消费场景支撑（涵盖旅游、租房/住宿、培训、运动健身、亲子、美业摄影、数码汽车配件、二手电商）。
- 绝不存在“单场景单一维度撑起一个角色”的硬凑情况。
- 各机制之间互斥清晰：A 针对宣传/承诺履约不对板，B 针对流程/时间/地点被单方打破，C 针对提前付款后的退款/清退受阻。

## 4. 问句排序与版本控制结论

- **题序保持现行 8 题顺序**：
  1. 跟团旅游（Q1） -> 2. 酒店订房（Q2） -> 3. 健身办卡（Q3） -> 4. 儿童乐园（Q4） -> 5. 培训报名（Q5） -> 6. 写真拍摄（Q6） -> 7. 电池售后（Q7） -> 8. 二手购物（Q8）。
- **问句语义版本**：
  - 本轮优先保持当前语义版本稳定，以保护现有答卷库不被破坏；
  - 针对 Q3、Q6 的微调若仅简化措辞而不改变事实触发条件，可在 N09 中由编辑评审确认是否升版本；如确认语义变更，严格递增版本号并隔离答卷统计。
